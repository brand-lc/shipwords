Ask before you clone

What is shipwords?

A free, MIT-licensed codebase for running many small AI image and video sites, one per keyword. Generation jobs, sign-in, credits, payments and free trials are written once and shared; each site has its own pages, look and domain.

How is it different from a paid SaaS boilerplate?

Most boilerplates give you one SaaS app. shipwords is built for running many AI sites at once: the shared core is fixed once for all of them, image and video generation is built in, and a real site's full source shows how to ship one.

What does it cost?

The code is free and MIT-licensed, commercial use included. You pay for the domain (about $10 a year at cost), your Cloudflare usage, Stripe or PayPal fees on each sale, and model fees on Yir per generation, which you cap per job in site.models.ts. Video sites that stitch clips together need Cloudflare's Workers Paid plan.

Do I need to know how to code?

You work in a code repo, but a coding agent does most of the writing: give it the keyword and it builds the pages, while sign-in and payments are already done. You should be comfortable running terminal commands and setting up Stripe and Cloudflare accounts.

Where does it run?

On Cloudflare. Each site is deployed on its own, with its own database, file storage and payment account, so you can launch or retire one without touching the rest.

Do I need a model API key to try it?

No. In test mode (UPSTREAM_MOCK=1, on by default) generations return sample results, so you can try sign-in, checkout and generation without any model key. Add an API key when you want real image and video models.
