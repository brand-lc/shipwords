在 GitHub 克隆

克隆之前，先问清楚

shipwords 是什么？

一套免费、MIT 开源的代码，用来同时运营很多个小型 AI 图像和视频站，一个关键词一个站。生成任务、登录、积分、收款和免费试用只写一次，所有站共用；每个站有自己的页面、外观和域名。

和付费的 SaaS 模板有什么不同？

多数模板给你的是一个 SaaS 应用。shipwords 为同时运营很多个 AI 站而建：公共核心修一处所有站都能更新，生图和生视频已经内置，还有一个真实站点的完整源码告诉你怎么上线。

要花多少钱？

代码免费，MIT 许可，可以商用。你要付的是域名（按成本价每年约 10 美元）、Cloudflare 的用量费、每笔订单的 Stripe 或 PayPal 手续费，以及 Yir 上按次计费的模型费用，每个任务的成本上限可以在 site.models.ts 里设定。需要把多段视频拼接起来的站，要开 Cloudflare 的 Workers Paid 套餐。

我需要会写代码吗？

你是在一个代码仓库里工作，但大部分代码由编程 Agent 来写：告诉它关键词，它就能把页面做出来，登录和收款已经写好。你需要能跑终端命令，会注册和配置 Stripe、Cloudflare 账号。

部署在哪里？

Cloudflare。每个站单独部署，有自己的数据库、文件存储和收款账户，上线或下线一个站都不影响其他站。

试用需要模型 API key 吗？

不需要。测试模式（UPSTREAM_MOCK=1，默认开启）下生成会返回样片，不填任何模型 key 就能试完登录、付款和生成。需要真实的图像和视频模型时，再填 API key。
